Návod: Jak aplikaci spustit na GitHub Pages

Celá aplikace je 100% obsažena v jediném souboru index.html (Vanilla JS + Tailwind CSS z CDN). Není potřeba žádný Node.js server ani build step!

1 Založit repozitář

Na GitHub.com klikněte na New repository (např. audiopen), nastavte jako Public a vytvořte.

2 Vložit index.html

V repozitáři klikněte na Add file → Create new file, pojmenujte jej index.html a vložte zkopírovaný kód.

3 Aktivovat Pages

Jděte do Settings → Pages, pod Build and deployment vyberte větev main / root a uložte.
